# Agent 域能力与运行时补全

本轮在 `taibu-agent` 实现域能力计划的 Phase 0–3，使用既有 Core、Pi Durable、用户设置和任务结算服务。按阶段保留独立本地提交，不推送 origin。

| 阶段 | 实现 |
| --- | --- |
| 0 | 15 个工具共用 11 份源 guide，构建期嵌入；目录按实际提供的工具过滤；旧方法 ID 与工具名别名兼容；后台压缩采用自适应阈值；漂移门纳入测试 |
| 1 | schema 驱动的参数准备；身份与种子策略、执行前新鲜权限检查；原生结果钩子提供候选成果提示；模型、工具及摘要 token 用量持久化并展示 |
| 2 | 有界 SSE 队列、空闲断线、epoch/resync；15 工具/11 体系独立评测；受限早报 Agent；问法模板及长期记忆管理 |
| 3 | task-owned 并行子会话、稳定提交收据恢复、禁止嵌套、整任务一次计费；白名单 MCP；视觉能力门控、真实图片评测入口；浏览器语音输入 |

知识正文唯一来源是 `skills/taibu-divination/interpretation/*.md`，共同约定取自 `skills/taibu-divination/SKILL.md`。生成器与 skill 打包器共享 `scripts/skill-guides.mjs`；生成文件逐字检查源内容。（这套 guide 已由方法卡取代：来源改为 `skills/taibu-divination/methods/*.md`，生成器为 `scripts/build-methods.mjs`，产物进入 `taibu-core/mcp`，见 [Pi 1.3.0 升级说明 · 阶段十](agent-pi-durable-1-3-upgrade.md#阶段十方法卡)。）SDK 桥接使用 Pi 原生系统分区重放与渲染，确保方法目录、行为指令和最新分区更新进入真实模型请求，已删除分区不会残留。修改知识或 Core 工具定义后运行 `pnpm build:methods`。

共享约定按完整章节提取，保留历法、时间、占当下、日期核实、随机性、六爻用神及 detailLevel 七项；独立按源文件行边界比对，防止多行正则把首条误当成整章。目录仅省略 Core 描述里已由工具 schema 承载的输出字段说明，完整约定与十一组路由仍保持在 1500 字符以内。

工具参数只修正可确定的表示错误；越界小时、不合法历法仍由 schema 拒绝，不能将错误出生信息静默改成另一张盘。身份、任务归属与随机种子由服务端确定。成果暂存和最终选择沿用既有事务；计算缓存重放仍重新检查权限。

并行子会话的 ID 映射写入原生 task Doc，和创建、配置一起提交。各项最多四个，只开放该体系 Core 工具及方法读取；不能追问、联网、写记忆或派生。父工具收集真实答案，父会话汇总并最终选择成果。停止级联取消子会话；重启复用同一子会话及 requestId。所有子会话用量通过 `Harness.usage()` 汇总，业务扣费仍只有父任务一次。

早报使用相同模型桥接与原生 Harness，工具仅有 `almanac`、当前用户已存命盘读取和黄历/八字方法读取。单次生成的内核使用 MemoryStorage，持久重试、租约、预占、退款和最终落库由既有 daily briefing job 负责。中断后重新生成该短作业；不创建聊天 Agent run 或另扣一次费用。无命盘或命盘功能关闭时明确说明，只给一般建议；关闭功能不会读取命盘。必须实际调用两个依据工具，缺失时最多提醒一次，仍缺依据或答案被截断则失败。SDK 同时遵守平台、原生模型及单次请求中最小的输出预算；早报普通模型上限为 2400 token，支持推理的模型为 8192 总 token，以容纳隐藏推理，平台配置的更小上限仍生效。

模板复用 `user_settings.chat_preferences` JSON，最多 20 个；`{{question}}` 字面替换当前输入，不自动发送。长期记忆需要跨会话独立查询、owner RLS、容量限制、来源和删除能力，故使用独立 `user_agent_memory` 表。默认关闭；Agent 保存正文必须等于用户原话并来自本任务真实用户消息或已采用的用户指令。写 RPC 检查新鲜开关、租约及取消状态，以用户/内容指纹去重。用户可手动保存、查看和删除，关闭开关保留已有记录。

MCP 固定 `@earendil-works/pi-mcp@1.0.4`（MIT，无安装生命周期脚本）。只从管理员环境读取服务和工具白名单，最多四个服务、每服务二十个工具；无通用模型指定地址或 stdio 执行入口。复用公开 HTTPS、socket DNS 私网/混合解析阻断及禁止重定向。密钥只由 `tokenEnv` 引用，服务指令不加入 prompt；凭据从返回文本中脱敏。外部工具标为 unsafe，结果不明时不自动重发副作用。

视觉初始请求和追加输入均检查平台模型能力，不支持时在扣费/提交前明确拒绝。附件继续校验 owner、会话引用、真实字节与哈希。语音使用浏览器 SpeechRecognition/WebKit API，无新前端依赖；只由点击启动，识别仅填入输入框，用户编辑后不会被覆盖，账号/草稿切换或卸载终止录音。浏览器可能使用在线语音服务；麦克风拒绝和不支持状态在界面提示。

## 独立评测

`pnpm eval:agent` 离线执行 15 个工具，并和对同一参数执行的 Core 规范 JSON/文本逐项比对；随机工具使用实际 ToolTask 的稳定种子。保留原 skill 的三个问题及质量断言；补充条目明确采用工具默认的可选参数，限定当前盘面与简短解读，以避免演变为需要额外资料的其他计算。离线评测不声称证明解读质量，也不加入 `verify` 的收费网络调用。

真实评测按需运行：

```bash
pnpm eval:agent -- --live --config /private/model-config.json --output .taibu-local/agent-eval-live.json
pnpm eval:agent -- --live --vision --config /private/vision-config.json --output .taibu-local/agent-eval-vision.json
pnpm eval:agent -- --live --config /private/model-config.json --resume .taibu-local/agent-eval-live.json --output .taibu-local/agent-eval-live.json
```

私有 JSON 使用 `AIModelConfig` 字段及 `apiKey`（或已有 `apiKeyEnvVar`），不可提交。真实模式同时检查 Core 一致性和模型质量评分，评分复用原生流式模型桥接，保留实际答案、Core 规范文本、失败条目与截断/中断状态供人工复核。模型评分是辅助判定。真实评测使用原生 Harness 与真实网关，账号、存储和权限使用 fixture；真实账号、数据库、扣费与恢复由固定栈另行验收。视觉用没有文字提示答案的几何图片检查颜色、形状、顺序及数量，实际图片通过 SDK image part 发送。

评分采用最多 8192 输出 token 和五分钟截止时间，只检查断言及答案实际引用的数据，不重新起盘。报告以私有权限原子替换，并在评分前保存已完成的分析。`--resume` 复用已算出的答案与实际 Core 文本，重试未完整返回的评分；已有明确不合格评分仍保留为不合格。`--case <工具用例 ID>` 可单独复查。

本轮未改动 Core 排盘算法。结构评测检查参数执行及规范结果一致性，不能替代独立算法校核。真实样本暴露的错误发生在答案解读：单日占星快照被扩成未来日期、四柱反推结束不含的区间被延长、六爻未来干支日期被手算错、出生生肖按公历年份猜测、奇门天盘/地盘/寄干混用。对应源指引已收紧依据边界，目录明确短回答也须加载指引；原答案、负面评分和截断状态均保留，同题新答案另作回归记录。

最后的知识正文及目录提示更新另通过 30 项方法/SDK/漂移/skill 检查，以及 lint 和严格类型检查；真实复测使用更新后的嵌入正文。质量评分属于样本验证，不保证模型后续每次回答均正确。

固定栈验收使用独立普通账号，未重建数据库或修改原账号凭据；保留原账号、记录与数据卷。默认演示账号经过既有多轮验收后聊天次数已为零，新账号仅用于本轮本地验收。私有账号配置、网关密钥及原始真实模型报告均在忽略目录内。

浏览器语音验收使用 SpeechRecognition 测试替身，已检查点击启动、草稿写入、停止/卸载和不自动发送；真实麦克风、浏览器在线识别服务与识别准确率未作硬件验收。MCP 进行了本地 HTTP 协议与出网边界验证，未调用第三方商业 MCP 服务。早报重试/预占/退款仍由既有持久任务与数据库契约覆盖，真实模型验证仅覆盖受限生成部分。

本轮只更新固定本地栈，未推送、合并 master 或部署生产。
