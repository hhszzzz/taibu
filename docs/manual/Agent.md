# Agent 使用与实现边界

## 使用方式

在聊天中启用 Agent，由后台 worker 连续执行推理与工具调用。平台模型遵循当前会员、模型权限与积分规则；BYOK 使用用户提供的模型连接，不扣平台模型积分。

Agent 可以调用排盘、命理拓展、知识库、历史对话与受控联网工具。计算和格式化复用 `taibu-core`，方法卡随 Core 维护；支持范围与算法参数见 Core 的 README 和 `ALGORITHM_RULES.md`。

模型菜单可配置代码模式与计划模式，默认关闭，对下一任务生效。代码模式在沙箱中组合调用受控工具，不能直接调用模型；计划模式允许先研究，提交计划并获用户批准后才可写入长期记忆、归档或派出子分析。低频工具通过工具搜索按需加载。

浏览器随请求带上所在的 IANA 时区（缺失或无效时按 `Asia/Shanghai`）。普通对话与 Agent 的每条新消息开头写入服务端收到时的「发送时间」（本地时间、星期与 UTC 偏移），任务中途插入、排队和回答问题的消息，以及交给协作成员和后台子分析的任务同样写入；系统提示词不含时间，不随分钟变化，便于模型服务缓存。占当下起卦起局、今天、今年与年龄都以最新一条的发送时间为准。只走人格提示词的一次性分析（如各占术结果页的解读）仍在系统提示词开头写北京时间。

多模型协作通过 `parallel_analysis` 分工后汇总；`background_agent` 提供可并行推进、自动回报并在同一对话中接续的常驻子分析，支持追加任务、停止与解散。成员工具受所选方法卡和体系边界约束。

## 任务状态与恢复

| 状态 | 行为 |
| --- | --- |
| `queued` | 等待 worker 取得租约 |
| `running` | 执行当前 checkpoint 和待处理命令 |
| `awaiting_input` | 等待用户回答，回复后继续 |
| `cancelling` | 已请求停止，等待执行与结算收敛 |
| `completed` / `failed` / `cancelled` | 终态，保留任务与可见历史 |

当前运行引擎为 `pi-durable/1.4.0`。只有匹配当前引擎的 worker 可以接管任务；SQL 定义刷新时，会结束当前引擎无法执行的未完成 checkpoint，并通过既有结算函数处理退款与状态，保留已完成历史和产物。

模型请求的所有来源都因过载、限流、网络或 5xx 失败时，任务持久休眠后重试两次（3 秒、6 秒），休眠期间 worker 可以停止或交接。回答失败时，用户在此期间插入的消息会接着开始下一轮回答，不会丢失。某一步连续 5 次让 worker 意外中断（未提交新状态）时，Pi 会停放该步，任务随即以失败结束并提示重新发起，不再无限重试。协作成员的模型按各自的上下文窗口决定压缩阈值。

任务 checkpoint、命令、工具调用收据和事件在 PostgreSQL 持久化。租约与递增 fence 拒绝旧 worker 的迟到写入。相同请求与工具提交重试保持幂等；用户追加、编辑排队消息和回答问题继续复用原任务。

停止请求不会回滚已经完成的外部操作。结算由任务生命周期决定：没有有效回复的失败可补偿，已有可见回复的停止按现有规则保留扣费。平台积分和结算记录在同一事务中处理，BYOK 不走平台积分扣费。

## 权限与凭据

- 用户只能访问自己的任务、对话、知识库和附件。管理员任务日志用于排查运行状态，不授予读取他人聊天正文的权限。
- 模型和工具权限在服务端校验；浏览器字段不能授予系统身份或改变任务所有者。
- 后台执行绑定任务所有者、当前会员状态和有效租约，缺少上下文时失败。
- 待恢复的 BYOK 凭据使用 `AGENT_CREDENTIAL_ENCRYPTION_KEY` 加密保存，终态清除。密钥必须由同一部署的 Web 与 worker 共享。
- 联网请求通过现有安全访问层，禁止访问私网和其他被拒绝的目的地址。

管理员可以在设置中心「功能与激活码 → 功能开关」分别关闭用户功能模块和 Agent 工具范围。模块开关会同时阻止对应的 Agent 排盘、详查和资料读取；Agent 工具范围还可以在不关闭用户页面的情况下收紧八字、知识库、联网/MCP、长期记忆、档案写入、协作和代码模式等能力。工具定义会保留在 Agent 上下文中，服务端在每次调用（包括缓存重放和脚本调用）前重新读取策略，关闭时向 Agent 返回可修正的权限错误。模块状态使用 `feature_disabled:<id>` 保存，Agent 范围使用 `agent_tool_disabled:<scope>` 保存，均由管理员 API 写入 `app_settings`。

管理员可在设置中心的 AI 服务中查看「Agent 任务」，按任务、对话或用户 ID 排查。任务树从持久化日志重建，结束后仍可查看；该接口裁剪聊天正文、工具结果和私有文档，只提供排障需要的运行信息。

## 命盘与保存

工具卡片使用实际返回的结构化产物，复用各占术已有视图。展开、固定或恢复命盘只展示已有结果，不重新排盘或调用模型。数据不完整时降级为规范文本。

桌面可固定到工作区，移动端使用全屏视图。工作区按账号与会话隔离；工具卡片和最终回复中的同一产物按 `artifactId` 去重。

任务完成不会自动把命盘或分析保存到用户档案。用户主动保存时，服务端验证任务与产物归属，保存已有计算结果，并保持幂等。长期记忆需要用户开启；归档事件绑定用户提供的事实、所属命盘与来源，编辑或删除时遵循现有来源边界。

## 设置与展示

`/settings` 进入 `/settings/general`。设置导航覆盖常规、账户、订阅、个性化、BYOK、命盘、知识库、MCP 和帮助；管理员配置入口继续执行服务端管理员检查。

分类切换保留当前工作区的草稿，离开时使用统一草稿保护。切换账号重新挂载面板，隔离上个账号的状态。旧 `#settings/...` 地址通过兼容桥转到页面路由。

浅深主题、字号和减少动画统一使用应用设置与 `src/app/globals.css`。命盘语义配色和普通回复的 Markdown、图表渲染沿用共享组件。

## 开发入口

| 位置 | 职责 |
| --- | --- |
| `src/lib/agent/api.server.ts` | API 用例与权限边界 |
| `src/lib/agent/store.server.ts` | 任务读写 |
| `src/lib/agent/runtime.server.ts`、`durable-storage.server.ts` | Pi 执行与持久化适配 |
| `src/lib/agent/tools.server.ts` | 工具装配与调用 |
| `src/lib/agent/tool-presentation.ts` | 工具结果展示映射 |
| `src/lib/agent/engine.ts` | 当前引擎版本 |
| `database/functions.sql` | 原子命令、租约、产物和结算函数 |
| `scripts/agent-worker.mjs` | worker 启动入口 |

本地启动使用 `pnpm local:update`；状态和日志使用 `pnpm local:status` / `pnpm local:logs`。平台配置以 `.env.example` 为准。修改运行或计费流程需执行对应单测、`pnpm test:db` 和浏览器验收；发布前执行 `pnpm verify`。
