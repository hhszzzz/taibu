# Core 算法口径与验证范围（2026-10）

本文对应 SDK 的 15 个公开领域、规范 text/json 与 MCP 契约。算法正确性指所声明规则下的计算、边界与输出一致性；传统术数的判断语句是规则推演，不构成预测效果的验证。不同流派的规则须用显式选项区分。

## 时间和历法

公历日期严格校验，支持公元 1–9999 的输入表示，不依靠 JavaScript 对 0–99 年的默认重映射。输入范围并不等于天文/历史历法全范围精度承诺。紫微与奇门明确限制为 1900–2100 年；四柱反推范围上限为 9998，单次最多 1200 年。

命理工具默认 `Asia/Shanghai`；占星省略时区时按坐标推导，无坐标默认 `Etc/GMT`。IANA 时区按运行环境时区数据库解析，服务器自身 `TZ` 不决定输入含义。夏令时重复与跳过时刻默认拒绝，支持 `earlier`、`later`、`compatible` 的工具在输出保存选择。反推默认排除无法唯一解析的分钟，并记录数量。

八字、六爻、奇门、六壬与传统太乙的交节通过输入时区解析实际时刻，再转换到历法库的固定 UTC+8 基准（`Etc/GMT-8`）；此基准不采用 `Asia/Shanghai` 的历史夏令时。明确带偏移的 ISO 时间戳保留原瞬间，不在重复时段重新消歧。大运 `startSolarTimezone` 同样标明固定 UTC+8，并独立保存出生时区和真太阳时来源。八字日/时柱取本地或真太阳时；`dayBoundary: midnight` 默认午夜换日，`zi` 为 23 点换日，时干仍采用历法库的子时规则。各领域的日界口径没有强行合并。

真太阳时采用经度相对于实际民用时区偏移的修正和 Astronomy Engine 均时差，按分钟四舍五入用于排盘，保留原钟表时间、均时差和偏移。夏令时解析发生在太阳时校正之前；跨日按完整日期处理。

## 必须保留的精度与流派限制

紫微 `exact` 沿用 iztro 2.5.4 / lunar-lite 0.2.7 的语义：本命年界采用立春日，而月界以代表时辰计算，不是出生分钟对应的物理交节时刻。这与八字的实际交节规则不同。自定义四化需要为每个覆盖天干提供按禄权科忌排序的四颗不同星曜。

紫微 `birthday` 按农历生日比较所有目标年份，沿用依赖的“生日次日递增”边界；闰生日在目标年存在同一闰月时取闰月，否则取同号普通月，小月按当月最后一天。年龄变化同步小限、大限／童限及其宫位和四化，不只改年龄数字。流时 Date 输入采用创建命盘时的时区，显式目标时区可覆盖；语言、配置与延迟方法隔离，数组排序回调和独立大限列表也纳入快照测试。

四柱反推窗口表示原始民用输入分钟，而非校正后的太阳时。非 `reject` 策略核验完整钟面，覆盖整小时和半小时 DST 缺口；1582 年历法缺日不使整次搜索中断。农历参数越出公元 1–9999 时，下一步调用回退为公历参数。扫描定期通过定时器让出执行权，仍逐分钟精确核验，不用近似均时差或候选截断换取速度。

奇门转盘的日时干支与展示四柱统一采用晚子换日。由于 taobi 的历史时区处理和午夜换日不可靠，旋转层仅接收同日时干支的现代参考日期与已确定的局数；真实交节、年月柱和定局仍用原始瞬间，且运行时核对后台日时干支。参考日期按运行环境的本地钟面构造，再按 taobi 实得日干支与目标之差整日平移一次（其纪日起点按运行时区的历史地方时换算），浏览器等无法改写 `process.env.TZ` 的环境与服务端排出同一转盘。飞盘中宫显示自身门迫／击刑；大格按天盘庚加地盘癸识别。格局逐对比对同宫天盘干与地盘干，寄干一并参断：转盘中五默认固定寄坤二（`zhiFuJiGong: ji_wugong`；`ji_liuyi` 为阳遁寄艮八、阴遁寄坤二）：中宫只留地盘干，不标星门神；中五地盘干作副干列于寄宫，天禽与所随之星（寄坤二时即天芮）同列于其落宫，天盘寄干随天禽落宫，入墓、击刑同样计入寄干。取《烟波钓叟歌》与《遁甲演义》两书皆载的格：三奇得使（乙加己辛、丙加戊庚、丁加壬癸）、刑格（庚加己）、上格（庚加壬，《遁甲演义》称小格）、伏宫/飞宫格（庚加值符六仪/值符六仪加庚）、伏干/飞干格（庚加日干/日干加庚，日格即伏干格）、岁/月/时格（庚加年/月/时干）；甲干一律取其所遁六仪。伏吟、反吟按“八门返伏皆如此”星门分论，八宫同时成立时只在全局格局列一条“全盘: 星伏吟”等；五不遇时按时干克日干且阴阳相同判定（己日乙亥、庚日丙戌同例），时干入墓取《遁甲演义》所列丙戌、壬辰、丁丑、癸未、戊戌、己丑。入墓按十二长生阳顺阴逆取墓：乙木长生午、墓戌，落乾六为正墓；另依五行同墓之说（木墓在未，《遁甲演义》“六乙日奇下临二宫”）在坤二标“乙(五行墓)”，两宫皆记入墓，`ruMuStems` 列出入墓之干。六仪击刑按全盘任一天盘六仪落刑宫判定（戊震三、己坤二、庚艮八、辛离九、壬癸巽四），不限值符。驿马按时支取（寅午戌马在申、申子辰马在寅、巳酉丑马在亥、亥卯未马在巳）；宫位空亡标记取日空（时空另列）。飞盘九星过中五按洛书顺逆飞布，星门伏吟、反吟逐宫各自判定，只有八宫同时成立才记为全盘格局。全局格局在默认详略档即输出。悖格、九遁中神遁以下诸遁、天网四张、九星旺衰等两书说法不一或需另立字段，暂未实现。

传统太乙使用《太乙金鏡式經》四库全书本卷三的阴阳七十二局表。该版本存在与现代软件不同的表项，不能用某一个程序作唯一真值。年积数取金镜 1936557 或统宗 10153917 加农历年；月计为现代农历适配且闰月重复，日/时积数参考固定版本 kintaiyi 的纪元（排除其后期日号修正和零值时局覆盖）。这不是原典古历月计/日计/时计的完整重建。完整太乙的八门、天禽、五福等星将体系和各派断法仍未实现；`accumulatedNumber` 可供调用者使用自己的纪元。公元前日期和传统分钟计不支持。

占星十行星为地心视黄经、真黄道/春分点 of date，包含光行时与光行差。交点、莉莉丝和宫头仍来自 circular-natal-horoscope-js 1.1.0，精度不能按十行星外推。`ayanamsa` 为调用者提供的固定偏移，不是自动计算的 Lahiri 等随历元变化的岁差体系。太阳回归等同星行运相位包含在结果中。

六壬唯一贼克优先级可独立穷举核对，但涉害、遥克、昴星等全部课表并没有原典逐条金标准覆盖。神煞/格局/旺衰等规则受流派影响；本次保留既有体系并修正已证实的问题，不应表述为穷尽所有古籍和流派。

## 六爻判定口径（不计分）

六爻分析不使用加减分或分数排序：每项结论由按次序判定的条文得出，依据写入 JSON「判据」。口径取《增删卜易》与《卜筮正宗》原文及所附占例，两书有别时的取舍写在 `domains/liuyao/calculate.ts` 对应函数的注释中。

- **旺衰**：月建临爻、月扶、月生为助，休囚逢月合「衰而亦旺」亦为助，月克为伤（月将章）；日辰临爻、生、扶、合为助，克为伤，长生、帝旺、墓、绝须看本爻有根无根，月令当权逢绝不绝（日辰章、生旺墓绝章觉子注）。日月有助无伤为有气，一助一伤为相敌、以动爻生克定胜负，皆不助为无气。
- **暗动、日破、月破**：静爻逢日冲，得月令之助为暗动（冲而带克仍为伤），休囚为日破；动爻逢冲不散（动散章）。逢月建相冲为月破，动爻亦论；临日建者逢破不破，惟他爻动克或本爻化回头克时破亦为破。破爻月内无功，静而无日辰动爻生助者为真破，其余出月、逢合、实破之日可用（月破章）。
- **旬空**：发动或有根之爻逢日冲为冲空则实；临月建、发动、旺相或得日建动爻生扶者旬内仍空、出空有用；休囚安静者为真空（旬空章、《卜筮正宗·旬空论》）。
- **化变与他爻生克**：一变兼几种关系时依次取主名：伏吟/反吟 → 进退神 → 回头克 → 墓绝与回头生相兼看本爻有无日月帮比 → 化墓/化绝 → 回头生 → 化空，其余写入说明。只有明动、暗动之爻能生克他爻；化回头克者，以及无气又逢月破、日月伤克、化退、化墓、化绝、化破者无力（元神忌神衰旺章）。
- **用神取用**：明现 → 变出 → 月日 → 伏神。多现时逐条比较，先分高下者定主用：持世 → 临月日（《卜筮正宗》第十七问）→ 旺衰 → 动静 → 伤损（两现章古法），诸条皆同者并看。同类中旬空、月破之爻不夺主用而另主应期（两现章「应乎旬空月破」及两书所附三例）。
- **伏神**：按飞伏神章「有用者六」「终不得出者五」两列判定；两列相抵时依次看旺相飞神克伏、被日月冲克而日月无助、休囚无气、日月相敌，其余有气者有用。伏神逢日冲论被冲，不论暗动。
- **应期**：先看用神之病：旬空待出空填实或冲空，月破待填实逢合，入墓待冲开，合住待冲开，冲空、暗动待逢合，绝待生旺，伏藏待出露；无病再看动静旺衰：静逢值冲，动逢值合，太旺逢墓冲，衰绝遇生旺，化进逢值合，化退忌值冲；受克者看克神（各门类应期总注、《卜筮正宗·伏神正传》）。输出分应期、吉期、忌期，只给逢某支的相对条件，不推算具体历日。
- **反吟、伏吟**：内卦、外卦分别论，只在该卦有爻发动而卦体改变时成立，卦中静爻随卦变亦在其内（反伏章比之井例）。伏吟惟乾震互变；爻之反吟惟坤巽互变；卦之反吟为后天方位相对的乾巽、坎离、艮坤、震兑互变（《卜筮正宗》反吟、伏吟卦定例）。反伏只作告诫，吉凶仍以用神旺衰定。
- **三合**：三支俱全且至少两支发动（明动、暗动之爻或动爻化出之支，同一动爻的本支与化出之支各算一支，见第四问大畜之乾例）方成局，第三支可为静爻，或由月建、日辰补足；只一支发动不成局（第四问「不动不成局」），合化五行的旺衰不作成局条件。局中有空、破、墓、合之爻待去病之日成局，无病而两动一静者待静爻值日（三合章、第四问）。三支只见其二的「虚一待用」尚未实现；半合沿用原法只作辅助，同一局已断成局或不成局者不再另列半合。

## 梅花判定口径（不计分）

梅花体用只论经卦，整卦五行（所属八宫）不参与生克。吉凶不加减分，按下列次序取第一条成立者，依据写入「判断参考.依据」。口径取《梅花易数》卷二体用总诀、衰旺论、卦断遗论及卷一占例。

- **体用与变卦**：不含动爻的经卦为体，含动爻者为用；互卦取本卦二至四、三至五爻，乾坤无互则互其变卦，靠体一侧为体互。变卦一段论用卦经动爻变出的经卦，体卦一侧不变（观梅占「幸变为艮土，兑金得生」）。用生体、体克用、比和为利，体生用、用克体为不利（体用总诀）。
- **判定次序**：一、互卦有生体之卦而变卦也生体者吉，互卦有克体之卦而变卦也克体者凶（卦断遗论「用不生体，互变生之而吉」「用不克体，互变俱克之而凶」）；二、用、互、变中有克体之卦而无生体之卦者凶，比和与体克用都不算生气（牡丹占「卦中无生意」，老人占、牛哀鸣占「并无生气」）；三、其余看用卦与变卦，用吉变凶先吉后凶，用凶变吉先凶后吉，同利为吉，同不利为凶（体用总诀）。旧版计分规则的「平」不再给出。
- **衰旺与体党**：体卦当令为旺、体势盛，逢月令所克为死、体势衰；体衰逢克其凶更甚，有生体之卦则衰稍解（衰旺论）。互、变与体卦同五行为体党，与用卦同五行为用党（体用总诀）。二者只写入依据，论轻重而不改吉凶。
- **不拘体用者**：卦名、卦辞与外应有时另主吉凶，如卦断遗论所举西林寺额与「今日动静如何」，以及枯枝坠地占以睽、损卦名断凶。工具不据此判定，留待解读参看。卷一观梅、牡丹、西林寺添勾、老人、少年、牛哀鸣、鸡悲鸣诸占与卷二乾上坤下占病六问，按体用所断都与上述次序相合。
